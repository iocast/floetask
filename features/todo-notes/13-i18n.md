# 13. Language support (P1)

floetask's interface in the user's language. Today every label already goes through `i18n::tr` / `trf` with an English table only; this section specifies how further languages are added, chosen and shown.

## 13.1 Scope

Translated:

- Every user-facing string of the GUI: menus, buttons, dialogs, settings and their descriptions, tooltips, toasts, empty states, error messages.
- Names of months and weekdays, and date formats in the calendar, the date picker and human-friendly dates ("today", "next week", "overdue").
- OS notification texts ("Due today", "Due in 3 days").

Not translated:

- The todo.txt file format. Keys stay as they are (`due:`, `t:`, `rec:`, `pm:`, `status:`, `note:`, `h:`), dates stay ISO (`2026-10-06`) and status values stay as written (`doing`, `waiting`).
- The search language: keywords (`and`, `or`, `not`, `due`, `today`, `pri`) stay English in queries, so saved filters work in every language. Localised aliases are a possible P2.
- Natural-language date input (`due:tomorrow`) keeps its English phrases; other languages are a P2 (§4.5).
- Command-line output (`--help`, `--paths`).
- Log and debug output.

## 13.2 Languages

| Wave | Languages |
|---|---|
| 1 | English (source), German |
| 2 | French, Italian, Spanish |
| 3 | Portuguese (Brazil and Portugal), Dutch, Polish, Czech, Turkish, Russian, Japanese, Korean, Simplified Chinese, Hindi |

A language ships only when all of its strings are translated (§13.8). Right-to-left languages (Arabic, Hebrew) are out of scope until the layout supports mirroring.

## 13.3 Choosing the language

- **Settings → Appearance → Language** offers **System** (default) and every shipped language, each listed by its own name ("Deutsch", "Français").
- **System** follows the operating system's UI language. The lookup falls back from the exact locale to the language to English: `de-CH` → `de` → `en`.
- Changing the language applies immediately, without a restart.
- The choice is stored as `language` in `config.toml` (`"system"`, `"en"`, `"de"`, ...). An unknown value falls back to System.
- Reading the OS locale is an application port with an infrastructure adapter, like every other OS access.

## 13.4 Translation files

- One [Fluent](https://projectfluent.org) file per language, `crates/floetask-gui/locales/<language>/floetask.ftl`, embedded into the binary at compile time; no files to install.
- Message ids are today's `tr` keys (`settings_title`, `calendar_more`, ...). English is the source of truth: a new string is added to the English file first.
- Placeholders are named instead of positional, so translators can reorder them: `calendar_more = +{ $count } more`.
- Plurals and grammatical variants use Fluent selectors: `{ $count -> [one] 1 todo *[other] { $count } todos }`.
- A string missing from a language falls back to English; the raw key is never shown.
- `tr` / `trf` stay the only way views get text; their signature changes to take named arguments.

## 13.5 Dates, numbers and layout

- Month and weekday names and the calendar's period titles ("Oktober 2026", "Dienstag, 6. Oktober 2026") follow the language. ISO dates on todo cards stay ISO unless human-friendly dates are on.
- The first day of the week keeps its own setting (Settings → Dates); its default follows the locale (Monday for most of Europe, Sunday for the US).
- Numbers in counts use plain digits; no thousands separators are needed for todo counts.
- Layouts must fit longer languages: German and French strings are often 30 % longer than English. Buttons and chips grow with their text; fixed widths only where text is truncated with an ellipsis on purpose.

## 13.6 Fonts

- The bundled UI font covers Latin, Greek and Cyrillic.
- Japanese, Korean, Chinese and Devanagari use a fallback font: the system's font where the OS provides one, otherwise a bundled Noto subset loaded only for those languages, to keep the binary small for everyone else.
- Todo text in any script always renders, whatever the UI language, through the same fallback.

## 13.7 Contributing a translation

- Copy `locales/en/floetask.ftl` to `locales/<language>/floetask.ftl`, translate the values, add the language to the list in `i18n.rs`, and run the tests.
- A short guide in `CONTRIBUTING.md` explains Fluent syntax, placeholders, plurals and the glossary (todo, project, context, threshold, status, board).

## 13.8 Quality checks

- A test fails when a shipped language misses a key the English file has, has a key English does not, or uses a placeholder English does not.
- A test fails when a view passes a literal string to a widget instead of going through `tr` (search for string literals in `text(...)` and `button(...)` calls under `view/`).
- A pseudo-locale (`en-XA`: every string lengthened by 40 % and wrapped in brackets) is available in debug builds to find clipped or hard-coded text.
- The GUI snapshot tests render the main screens in English and German.

## 13.9 Acceptance criteria

1. With the OS set to German and Language on System, floetask starts in German; switching to English in Settings changes every visible string at once.
2. No English string remains visible in German on the list, board, calendar, todo dialog, drawer, settings and About page.
3. A todo file written in the German UI is byte-identical to one written in the English UI.
4. Saved filters written in one language work unchanged in the other.
5. The calendar shows German month and weekday names, starting the week on Monday.
